# افزونهٔ ارزیاب بیمه تکمیلی

افزونهٔ Chrome (Manifest V3) برای `iapui.ostaadx.ai`: وقتی بخش «داروی مصرفی» در صفحه پیدا شود، تصاویر `blob:` مدارک را جمع می‌کند، با OCR ایبو متن آن‌ها را استخراج می‌کند و نتیجه را با DeepSeek (از طریق `backend.py`) ارزیابی می‌کند.

## نصب

1. بک‌اند را یک‌بار آماده کنید:

   ```bash
   pip install -r requirements.txt
   playwright install chromium
   python -m deepseek.auth      # یک‌بار ورود به DeepSeek
   python backend.py            # http://127.0.0.1:8000
   ```

2. در Chrome به `chrome://extensions` بروید، **Developer mode** را روشن کنید.
3. **Load unpacked** را بزنید و پوشهٔ `extension/` را انتخاب کنید.

## استفاده

1. `python backend.py` باید در حال اجرا باشد.
2. صفحهٔ مدارک را در `https://iapui.ostaadx.ai` باز کنید.
3. وقتی بخش `//*[@id="content"]/main/div[2]` عبارت «داروی مصرفی» را داشته باشد، یک دکمهٔ کوچک **«ارزیابی مدارک»** پایین صفحه ظاهر می‌شود. تا وقتی روی آن نزنید هیچ تصویری جمع‌آوری، OCR یا ارزیابی نمی‌شود.
4. با کلیک روی دکمه، پنل باز می‌شود و کل فرایند (جمع‌آوری تصاویر → OCR → DeepSeek) اجرا می‌شود. نتیجه در همان پنل نمایش داده می‌شود و امکان پرسش پیگیری هم وجود دارد.
5. دکمهٔ تاگل در پنل و در پنجرهٔ افزونه، کل افزونه را خاموش/روشن می‌کند.

## تنظیمات (پنجرهٔ افزونه)

| تنظیم | پیش‌فرض | توضیح |
| --- | --- | --- |
| توکن ایبو | توکن موجود در `job.txt` | برای API `eboo.ir/api/ocr/getway` |
| آدرس بک‌اند | `http://127.0.0.1:8000` | همان `backend.py` |
| ذخیرهٔ خودکار تصاویر | خاموش | تصاویر را در `Downloads/eboo-docs/` ذخیره می‌کند |

## نحوهٔ کار

- **فعال‌سازی دستی:** XPath ثابت `//*[@id="content"]/main/div[2]` بررسی می‌شود (با نرمال‌سازی ی/ک عربی). تغییرات SPA با `MutationObserver` و تغییر URL رصد می‌شود. وقتی عبارت «داروی مصرفی» پیدا شود، فقط دکمهٔ «ارزیابی مدارک» نمایش داده می‌شود؛ اجرای خودکار وجود ندارد و کاربر باید شروع را بزند.
- **جمع‌آوری تصاویر:** همهٔ `img[src^="blob:"]`، `a[href^="blob:"]`، background-image های blob، و در صورت نبود هیچ blob، canvas ها. iframeهای same-origin هم پیمایش می‌شوند.
- **پیوست‌های صفحه‌بندی‌شده:** در نمایشگر مدارک فقط صفحهٔ فعال به‌صورت `blob:` در DOM وجود دارد. افزونه دکمه‌های ۱، ۲، ۳… کارت «پیوست‌ها» را به‌ترتیب می‌زند، بلافاصله بعد از هر کلیک بایت‌های blob را می‌گیرد (پیش از اینکه URL قبلی revoke شود) و در پایان صفحهٔ اولیه را برمی‌گرداند.
- **lazy loading:** یک اسکرول خودکار سریع انجام می‌شود و در حین اسکرول، هر blob جدید بلافاصله fetch و به OCR فرستاده می‌شود تا با virtualize شدن از دست نرود. موقعیت اسکرول در پایان بازگردانده می‌شود.
- **OCR:** در service worker انجام می‌شود (دور زدن CORS)، با همان دو مرحلهٔ `addfile` و `convert` (`method=4`, `output=txtraw`).
- **ارزیابی:** متن همهٔ اسناد به `POST /api/analyze` محلی ارسال می‌شود. `sh.md` سمت بک‌اند خوانده می‌شود.
- **پنل:** داخل Shadow DOM ساخته می‌شود تا CSS سایت به آن نفوذ نکند. Markdown با `marked` (باندل‌شده) و سپس sanitize می‌شود.

## نکات و محدودیت‌ها

- **بک‌اند الزامی است:** افزونه خودش نمی‌تواند به DeepSeek وصل شود (نیاز به session و PoW دارد).
- **همهٔ blob ها پردازش می‌شوند** (طبق درخواست). اگر صفحه لوگو/آواتار blob داشته باشد، آن‌ها هم OCR می‌شوند و ممکن است خطا بدهند؛ خطاها نادیده گرفته می‌شوند و بقیه ادامه پیدا می‌کنند.
- **توکن ایبو داخل کد است.** اگر افزونه را با کسی به اشتراک می‌گذارید، توکن را از پنجرهٔ افزونه عوض کنید یا کد را خصوصی نگه دارید.
- Service worker کروم حداکثر حدود ۵ دقیقه برای هر درخواست زنده می‌ماند؛ OCR چند سند + ارزیابی معمولاً زیر این حد است.
- اگر پس از reload کردن افزونه پنل قدیمی از کار افتاد، صفحه را یک‌بار رفرش کنید.
- اگر OCR روی یک تصویر شکست بخورد، همان تصویر با نشان «خطا» می‌ماند و بقیه ادامه می‌یابند.
- حداکثر ۳۰ صفحهٔ پیوست در هر اجرا بررسی می‌شود. اگر مدارک بیشتری دارید، صفحه را روی صفحهٔ بعدی بگذارید و «اجرای مجدد» بزنید.
- viewer فعلی تصویری است؛ اگر سندی به‌جای `<img>` داخل iframe/PDF نمایش داده شود، توسط این روش برداشته نمی‌شود.

## تست

```bash
venv/Scripts/python.exe tests/extension_smoke.py    # blob + lazy loading
venv/Scripts/python.exe tests/pagination_smoke.py   # صفحه‌های ۱..N و revoke شدن URL قبلی
```

تست‌ها یک پنجرهٔ Chromium مرئی باز می‌کنند و صفحهٔ هدف، ایبو و بک‌اند را محلی mock می‌کنند.

## عیب‌یابی

| نشانه | علت / راه‌حل |
| --- | --- |
| «بک‌اند در دسترس نیست» | `python backend.py` اجرا نیست یا پورت/آدرس در تنظیمات اشتباه است. |
| خطای 503 / login required | `python -m deepseek.auth` را اجرا کنید (یا `SERVER_INTERACTIVE_LOGIN=1`). |
| «تصویری پیدا نشد» | مدارک lazy هستند؛ صفحه را دستی اسکرول کنید و «اجرای مجدد» بزنید. |
| دکمهٔ «ارزیابی مدارک» دیده نمی‌شود | یا عبارت «داروی مصرفی» در بخش هدف نیست، یا افزونه خاموش است. صفحه را رفرش کنید و روشن بودن افزونه را در پنجرهٔ آن بررسی کنید. |
| «افزونه در این صفحه فعال نیست» | صفحه را رفرش کنید؛ افزونه فقط روی `https://iapui.ostaadx.ai/*` فعال است. |
| OCR همهٔ تصاویر خطا می‌دهد | توکن ایبو را در پنجرهٔ افزونه بررسی کنید. |
